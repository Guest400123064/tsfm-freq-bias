# ICLR 2027 blog post

This directory mirrors the file layout accepted by the
[ICLR 2027 Blog Post track](https://iclr-blogposts.github.io/2027/submitting/).
The Markdown post, its BibTeX bibliography, and its post-specific image and HTML
folders are the only files to copy into an official submission fork.

The current post is a scaffold. Its storyline and evidence will be consolidated from
the existing root draft after the refactoring plan is agreed.
